# Personal Finance Tracker

A personal finance management application built with Python.

This is my first independent Python development project. The goal is to gradually transform a simple console application into a fully functional backend service.

## Features (v0.1)

- Add income
- Add expenses
- Check current balance in KZT
- Validate user input
- Prevent spending more than the available balance
- Interactive command-line interface

## Technologies

- Python 3

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository or download the project.
3. Open a terminal in the project directory.
4. Run:

```bash
python a.py
```
